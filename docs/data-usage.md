# 数据与资源使用说明

本游戏允许游客直接游玩。用户主动点击微信登录时，微信云服务通过可信调用上下文识别该小游戏下的账号；云函数将 AppID 和 OpenID 转换为本游戏专用的 SHA-256 玩家标识及默认称呼。哈希标识仍可关联用户，并非匿名数据。

客户端不读取微信头像、昵称、手机号、通讯录、位置或相册；不接入广告、支付或行为统计 SDK。登录状态和玩家标识只保存在本次运行内存，重新进入后恢复游客。退出仅清除此游戏进程中的会话，不注销微信账号。

云函数不写入自建数据库、不主动输出身份日志。云开发平台自身的运行日志、计费与服务记录由该环境的设置管理。账号运营者应按实际部署、日志保留设置和微信后台当前要求完善本游戏的用户隐私保护指引及联系信息。

最高纪录和声音偏好仅写入当前设备的命名空间存储 `wx-mini-starter:`。目前没有云存档、跨设备成绩同步或云排行榜；清除微信中该游戏的本地数据后，本机纪录和偏好会丢失。

好友邀请由用户主动操作，使用固定标题与原创分享图，不包含玩家标识或任何账号信息。游戏不读取接收者，也不依赖分享送达判断提供奖励。

所有音频、游戏图标和分享图均随包提供，不从外部素材网站加载；授权说明保存在资源目录中。云登录调用与微信原生分享功能以外，当前游戏没有其他业务网络请求。
